# Sam Snippets — Portfolio Website

A personal portfolio website built with vanilla HTML, CSS, and JavaScript. It showcases who I am, my tech stack, my projects, and includes a contact section — with a dark/light theme toggle and smooth animated UI.

🔗 **Live Demo:https://sampad7.github.io/


## ✨ Features

- **Hero section** with animated typing effect and gradient text
- **About** section with profile photo and quick stats (projects, years of experience)
- **Skills** section showing tech stack (HTML, CSS, JavaScript, Python) with animated skill cards
- **Projects** section with a paginated grid to browse recent work
- **Contact form** to get in touch directly from the site
- **Dark / Light theme toggle**
- **Social links** — GitHub, LinkedIn, Instagram, and Email
- Fully responsive, single-page layout with smooth scroll navigation

## 🛠️ Built With

- **HTML5** — structure and content
- **CSS3** — custom styling, gradients, glassmorphism effects, and animations
- **JavaScript** — interactivity (theme toggle, typing animation, project pagination, form handling)
- **Google Fonts** — Montserrat

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/Sampad7/PORTFOLIO-WEBSITE.git

# Navigate into the project folder
cd PORTFOLIO-WEBSITE

# Open index.html in your browser
```

No build tools or dependencies required — it's plain HTML/CSS/JS, so it runs directly in any modern browser.
